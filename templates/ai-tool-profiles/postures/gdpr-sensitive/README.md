# GDPR-Sensitive Posture

Use this when:

- the project handles personal data, HR data, support exports, legal data, or regulated customer records,
- AI tools or builders could see user-level records,
- retention, deletion, export, and breach handling matter as much as code security.

Key characteristics:

- no raw personal data in prompts or workspace by default,
- pseudonymized or synthetic data only for AI-assisted work unless explicitly approved,
- prompt retention, shared memory, and broad knowledge uploads treated as privacy risks,
- DSAR, deletion, and breach-impact paths require manual review.
